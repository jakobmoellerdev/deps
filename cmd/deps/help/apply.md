Resolves every dependency, prints the same report as `deps plan` on stderr, and writes the changed files, including `go mod tidy` output (`go.mod`, `go.sum`), regenerated `package-lock.json`, `npm-shrinkwrap.json`, `pnpm-lock.yaml`, `yarn.lock`, `bun.lock`, `uv.lock`, `poetry.lock` or `Pipfile.lock`, `Cargo.lock` updated with `cargo update`, `Gemfile.lock` updated with `bundle lock`, `composer.lock` updated with `composer update`, `Manifest.toml` updated with Julia's Pkg, and the `--hash` lines of requirements files (pip-compile/`uv pip compile` output is regenerated from its header command, other files get the new release's hashes from the index). An update of a pip-compile input (`requirements.in`) rewrites the input and regenerates every compiled file named after it. Post-processors run on temporary copies; a failed one drops that module's or lockfile root's changes and is reported as an error. An update a post-processor finds inapplicable (a compiled requirements file whose inputs do not admit the version, a Go module version that declares another path) is left out instead, and the other updates of its files are applied: it is reported as `skip    <file>:<line>  <name>  <from> -> <to>  (cannot be applied: <reason>)`, counts as skipped, and is no error.

A dependency with updates in several PR buckets contributes one update to the files: the newest non-major one, else the lowest major. Its other updates are reported with `, separate PR`, as is the lock file maintenance update (`lockFileMaintenance`), which only `deps run` makes.

The `postUpgradeTasks` of the config run in `--dir` after the files are written, in the order `run` uses, when `--allow-tasks` (or `$DEPS_ALLOW_TASKS`) allows each of their commands. Otherwise nothing is written and the error names the first command not allowed. With `files` globs, every other file below `--dir` the commands changed is restored to its state before them (ignored files are left alone).

The platform is only detected from CI environment variables. Locally, lookups run without a platform token unless one of the token variables is set (see `deps help environment`).
