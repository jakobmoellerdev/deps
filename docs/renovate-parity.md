# Renovate parity for open-component-model

Gap list between OCM's Renovate setup (`open-component-model/.github/renovate.json5`, the presets it extends, and the `# renovate:` markers in the repository) and `deps`. Work through it top to bottom; each item is self-contained. Status: `done`, `open`, `deferred` (known gap, intentionally not implemented for now), `config` (expressible today with `.deps.yaml`, no code needed), `n/a` (not used by OCM or not applicable).
